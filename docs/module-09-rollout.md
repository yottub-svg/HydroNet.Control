# Модуль 09 — план поэтапного внедрения

1. Пилотный район: подключить одну насосную станцию и откалибровать пороги давления.
2. Второй этап: добавить соседние районы, сравнить тревоги с подтвержденными выездами ремонтных бригад.
3. Третий этап: включить автоматическое формирование `RepairCrewOrder` после подтверждения диспетчера.
4. Перед каждым расширением проверять ложные срабатывания, потерю связи и корректность восстановления после перезапуска.

Целевая метрика приёмки — обнаружение вероятного порыва и вывод тревоги на пульт не позднее 30 секунд от получения подтверждающего набора измерений. Откат выполняется отключением нового района без остановки уже подключённых источников.
