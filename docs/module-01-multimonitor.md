# Модуль 01 — мультимониторный пульт

`DispatcherForm` использует `Screen.AllScreens`, выбирает второй рабочий экран при наличии и записывает состояние выбора объекта в `ScreenStateStore`. Карта и тревоги используют один store, поэтому выделение `PS-01` не расходится между окнами. При одном мониторе применяется безопасный fallback на основной экран.
