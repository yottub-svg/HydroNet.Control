# Модуль 11 — сеть и разграничение доступа

- VRRP разрешён только между двумя серверными узлами в выделенном VLAN.
- Репликация БД и health-check проходят по отдельным разрешённым правилам firewall.
- Публичный интерфейс принимает только HTTPS/API-трафик через Nginx; административные порты закрыты от пользовательских подсетей.
- Роли диспетчера, старшего инженера и аудитора разделены; Break-Glass требует одобрения старшего инженера.
- Журнал аудита содержит субъект, ресурс, решение, срок JIT-доступа и результат операции.

Перед вводом выполняется проверка deny-by-default, отсутствия широких broadcast-правил и корректности ротации журналов.
