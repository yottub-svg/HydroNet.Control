# Модуль 02 — Alarm Fatigue UX

`AlarmFatigueReducer` объединяет каскадные события по `RootCauseId`, выбирает минимальный приоритет (P1 важнее P3), сохраняет временной порядок и формирует `FocusMessage` по первой тревоге первопричины. UI может показывать один фокусный инцидент вместо десятков повторов.
