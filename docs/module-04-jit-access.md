# Модуль 04 — Break-Glass / JIT Access

Запрос требует пользователя и причины. Одобрение другим пользователем выдаёт доступ на 15 минут; self-approval запрещён. Каждая операция попадает в неизменяемую очередь `AuditEntry`. Проверка `IsActive` закрывает доступ после TTL и не зависит от состояния UI.
