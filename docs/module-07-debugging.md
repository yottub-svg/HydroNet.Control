# Модуль 07 — отладка reconnect и GC

В обработчиках нет блокирующих `.Wait()`/`.Result`; буфер тревог ограничен жизненным циклом coordinator и очищается после replay. Фоновая реконнекция не трогает WinForms-контролы напрямую — обновление состояния выполняется через store и UI synchronization context.
