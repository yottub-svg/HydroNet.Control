# Модуль 08 — техническое задание диспетчерской системы

## Назначение

HydroNet.Control объединяет телеметрию насосных станций, тревоги давления и ремонтные наряды в едином пульте диспетчера водоканала.

## Функциональные требования

- принимать поток `PumpStation` и `PressureAlert`;
- локализовать вероятный порыв по градиенту давления между соседними задвижками;
- формировать `RepairCrewOrder` с участком, приоритетом и временем создания;
- отображать состояние источников и деградацию вторичных данных;
- поддерживать 24/7-режим: крупные статусы, клавиатурный фокус, отсутствие блокирующих вызовов в UI.

## Нефункциональные требования

Все операции I/O асинхронны, доменная логика вынесена в `HydroNet.Core`, а UI не обращается к SQL/HTTP напрямую. Проверка выполняется командами из корневого README.
