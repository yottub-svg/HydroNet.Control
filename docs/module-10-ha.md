# Модуль 10 — отказоустойчивая серверная пара

`ops/keepalived/keepalived.conf` фиксирует VRRP-виртуальный IP для пары API-узлов. На каждом узле запросы принимает Nginx и передаёт их Kestrel; health-check исключает неисправный узел из обслуживания.

План переключения: обнаружение отказа по health-check, перенос VIP на резервный узел, восстановление маршрута через Nginx. Целевой SLA переключения — не более 3 секунд. Состояние JIT-аудита должно храниться во внешнем общем хранилище при промышленном развёртывании, чтобы failover не терял журнал.
