# Модуль 12 — публикация и эксплуатация клиента

Клиент публикуется self-contained для `win-x64`; чек-лист MSI/MSIX находится в `installer/README.md`. Пакет создаёт ярлык в меню «Пуск» и на рабочем столе, поддерживает тихую установку, автозапуск и recovery после аварийного завершения.

При закрытии и повторном запуске сохраняется раскладка мониторов и состояние пульта в `%ProgramData%\HydroNet.Control`. Перед выпуском выполняются `dotnet test`, smoke-проверка API `/health`, проверка второго монитора, восстановления после потери SignalR и чистая установка на тестовой Windows-машине.
